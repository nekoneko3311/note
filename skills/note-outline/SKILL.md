# note-outline — 発信note構成作成（承認ゲート）

発信note記事の骨組みを設計する工程。リード・見出し・締めCTAまで設計し、**必ず一度止まって承認を得てから本文（note-write）へ進む**。

> これは自分の発信・集客note専用。クライアントから請け負うSEO記事には向かない。

## 参照

**最初に `~/note-kit/note-themes/` のテーマ設定を読む。** どのテーマかが決まっていなければ、ここで聞く。

テーマ設定から引くもの：

- **読者**（誰に向けて書くか）
- **ジャンル・扱う話題**
- **記事の目的**（信頼づくり／集客／販売。**締めの誘導の強さがここで変わる**。信頼づくりなら売り込まない、集客なら次の一歩へ、販売なら申し込みまで運ぶ）
- **立ち位置・強み**（うまくいかなかった経験＝自己開示の素材／実績・いま取り組んでいること＝数字の素材。**収入・売上の額は見出しにも構成にも使わない**＝note-write の「コンプラ」）
- **文章のサンプル**（あれば。見出しの言い回しをここに寄せる）
- **お手本にしたい書き手**（あれば。見出しの付け方とリズムだけ参考にする。**丸写ししない**）
- **記事の長さとペース**（想定文字数はここから引く。無記入なら 2,500〜4,000字）
- **効いたネタ**（過去に反応がよかったもの。ネタ選びの手がかり）
- **誘導先**（階段CTAの中身）
- **CTA固定画像**（その節があれば。毎回入れるバナーの位置）
- **触れない話題**（**構成に入れない**。見出しにも例にも出さない）
- **使ってはいけない表現**

## 入力

- ネタ（書きたいテーマ・読者からよく聞かれること・SNSで反応がよかった投稿など）／狙い（読者に何を持ち帰ってほしいか）
- 参考にする過去note（あれば）

誘導先はテーマ設定にあるので、毎回聞かない。

## この記事の「型」

- **タイトル**：数字＋具体的な成果＋実行内容＋ジャンル（例「1日15分で〜する5STEP」「3ヶ月続けてわかった〜のコツ7つ」）
- **リード（書き出し）**：①問題提示（読者の"あるある"な悩み）→②解決イメージ（読み終えた後の姿）→③読むメリット→④安心感（「難しい準備は要らない」「今日全部やらなくていい・まず保存」）
- **本文 H2**：4〜7本。行動指向の言い回し（「〜の全体像」「〜だけで質が上がる」「まず〜を1つ作る」）
- **各H2内の H3**：疑問解決型（「なぜ〜か」「〜の中身はこれ」）に加え、**自己開示エピソード（「僕も最初は〜だった」）を1つ挟む**
- **逃げ道**：各セクションに「まずここだけでOK」「今日のゴール」など、ハードルを下げる一言
- **締め（階段CTA）**：(a)成功イメージ再提示＋振り返り → (b)「ここから一気に加速したい人へ」 → (c)**テーマ設定の誘導先1つ目** → (d)**2つ目** → (e)**3つ目**（多くは「スキ」依頼）
- **CTA固定画像**：テーマ設定に「CTA固定画像」の節があれば、その表のとおりの位置を締めの設計に組み込む。**画像を続けて並べず、あいだに文章を挟む**。節が無いテーマでは何も入れない

## 設計の手順

1. テーマから、読者が抱く悩み・つまずきを5〜10個書き出す
2. 悩みに答える論点を選び、H2を4〜7本に整理（上から H2/H3 だけ拾って話が通る MECE に）
3. 各H2に、入れる要素をメモする（具体例・数字・手順・自己開示・逃げ道・今日のゴール）
4. リード方針（4ステップ）とタイトル案を2〜3個出す
5. 締めCTAの導線を、テーマ設定の誘導先どおりに並べる。**強さはテーマ設定の「記事の目的」に合わせる**。**CTA固定画像があれば、その位置も一緒に書き込む**
6. 全体の文字数感を置く（**テーマ設定の「記事の長さとペース」に従う**。無記入なら 2,500〜4,000字）

## 承認ゲート

- 構成案を提示し、最後に必ずこう聞く。
  > この構成で本文を書いてよいですか？（直したい見出しがあれば教えてください）
- 修正指示があれば直して再提示する。承認が出たら **note-write** を案内する。

## 出力フォーマット（そのまま note-write に渡せる形）

```
タイトル案：…（2〜3個）
狙い／誘導先：…
リード方針：問題提示→解決イメージ→メリット→安心感（1行ずつ）

## H2（見出し）｜入れる要素：具体例/数字/自己開示/逃げ道/今日のゴール
### H3（疑問解決型）
### H3
（H2ごとに繰り返し）

## まとめ＋CTA：振り返り→ここから加速したい人へ→［CTA固定画像1］→（誘導先1）→［CTA固定画像2］→（誘導先2）→（誘導先3）→［CTA固定画像3］
想定文字数：◯◯字
```

（`［ ］` の中身と並び順はテーマ設定の「CTA固定画像」の表どおりにする。節が無いテーマでは `［ ］` を書かない）

## 注意

- 承認前に本文へ進まない。
- 見本記事の表現をそのまま写さない。型は真似ても、言葉は独自にする。
- 専門用語は「言い換えを添える」前提で設計する（テーマ設定の読者の知識レベルに合わせる）。
- 画像を入れる位置も一緒に決める。**ワンスクロールに最低1枚＝500字に1枚**が目安（note-image 参照）。
