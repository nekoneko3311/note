# CTA固定画像の置き場所

記事の最後に**毎回入れるバナー画像**（セミナー告知・LINE誘導・特典案内など）を、ここに置きます。

## 使い方

1. このフォルダの中に、テーマ名のフォルダを作る（例：`ai-fukugyo`）
2. その中に画像を入れる（`.png` `.jpg` `.jpeg` `.webp`）
3. テーマ設定（`../note-themes/<テーマ名>.md`）の「CTA固定画像」の表に、ファイル名・入れる場所・altテキスト・画像のリンク先（画像を押したときに開くURL）・下に置くURLを書く

```
note-assets/
└── ai-fukugyo/
    ├── seminar.png
    ├── tokuten.png
    └── line.png
```

記事を書くとき、ここから記事フォルダの `images/` へ自動でコピーされます。

## 毎回入れるバナーが無い場合

**このフォルダは空のままで大丈夫です。**
そのときは、テーマ設定の「CTA固定画像」の節を**まるごと消してください**。
節が残っていると、記事を書くたびに画像を探しに行って止まります。
