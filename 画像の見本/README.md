# 画像の見本

このキットで実際に作れる画像です。**すべてAIが自動で作ったもの**で、手直しはしていません。

> 画像は**Codex（ChatGPT Plus以上で使える道具）を入れるかどうか**で、作れるものが変わります。
> 下の表の「Codexあり」と「Codexなし」で分けて見本を入れてあるので、見比べてから決めてください。
> **どちらでも、各プランで使える量の範囲なら、1枚ごとの追加料金はかかりません。**

### Codexを入れた場合

| ファイル | 何の見本か | いつ使うか |
|---|---|---|
| サムネイル-型A-完全ガイド.png | 見出し画像の基本形 | **迷ったらこれ。** ノウハウ・手順・まとめ記事 |
| サムネイル-型A-議事録.png | 型Aを別のテーマで作った例 | 同じ型でも、記事が変わるとこう変わります |
| サムネイル-型B-ロードマップ.png | 日数・ステップで区切る形 | 「5日間で」「3ステップで」の記事 |
| サムネイル-型B-5日間.png | 型Bを別のテーマで作った例 | 下段のカードが日数ぶん並びます |
| サムネイル-型C-特典.png | 特典つきを前に出す形 | 特典やプレゼントがある記事 |
| サムネイル-型C-テンプレ配布.png | 型Cを別のテーマで作った例 | この型だけ、人物イラストと金色の装飾が入ります |
| 挿入図解-比較2カラム.png | 人物イラスト入りの図解 | 「今までのやり方／新しいやり方」の対比 |
| 挿入図解-チャット風.png | AIとのやりとりを見せる図解 | 話し方・頼み方を説明するとき |

### Codexを入れない場合（図解のみ）

人物イラストと見出し画像は作れませんが、色も文字も揃った図解が作れます。

| ファイル | 何の見本か | いつ使うか |
|---|---|---|
| 挿入図解-Codexなし-流れ.png | 矢印でつなぐ流れ図 | 順番に進む手順を見せるとき |
| 挿入図解-Codexなし-数字.png | 数字を大きく見せる図 | 目安の数字を印象づけたいとき |

### どちらでも作れるもの

| ファイル | 何の見本か | いつ使うか |
|---|---|---|
| 操作画面-注釈つき.png | 画面に赤枠・矢印・注釈を入れた画像 | 「登録のしかた」など、画面を見せたいとき |

## 作り方

Claudeのアプリに「**noteを書いて**」と伝えれば、記事と一緒に自動で作られます。
画像だけ作りたいときは「**サムネイルを作って**」「**この見出しの図解を作って**」と伝えてください。

見出し画像は3つの型から選べます。指定がなければ型Aで作ります。
「型Bで作って」「ロードマップ型で」のように伝えれば、その型で作ります。

**いつも使うサムネイルの型**（A / B / C）と、**図解に人物イラストを入れるかどうか**は、
テーマ設定（`note-themes/` の中のファイル）の「画像の好み」の欄で決められます。

## 操作画面のスクリーンショットも作れます

「登録のしかた」「設定の手順」など、実際の画面を見せたい箇所では、画面を撮って
**赤い枠・矢印・注釈の文字**を入れられます（見本：`操作画面-注釈つき.png`）。
「この画面を撮って、ここに注釈を入れて」と伝えてください。**Codexが無くても作れます。**

## 色を変えるには

テーマ設定（`note-themes/` の中のファイル）の「図解の配色」に、メインの色を1つ書いてください。
記事の画像がすべてその色で揃います（初期設定はオレンジです）。

## Codexを入れるかどうかの早見表

見出し画像（サムネイル）と人物イラストには、**Codex**（ChatGPT Plus（日本では月3,000円ほど）以上で使える道具）が必要です。
入れない場合に作れるもの・作れないものは、次のとおりです。

| | Codexを入れた | 入れていない |
|---|---|---|
| 見出し画像（サムネイル） | 作れる | **作れない**（ご自身で用意） |
| 記事に差し込む図解 | 作れる | **作れる**（`挿入図解-Codexなし-◯◯.png` の2枚が見本） |
| 人物イラスト | 作れる | 作れない |
| 操作画面のスクリーンショット | 作れる | 作れる |
| 1枚ごとの追加料金（各プランで使える量の範囲で） | なし | なし |

あとから入れることもできます。入れ方は「はじめにお読みください.md」の付録の「6. 画像づくりの道具（任意）」にあります。
