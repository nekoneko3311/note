# note記事のテーマ設定

note系スキル（note-auto / note-outline / note-write / note-image / note-toukou）が読む設定の置き場。

**ジャンルを増やしたいときは、ここにファイルを1枚足すだけ。** スキル本体は触らない。

## いまあるテーマ

| ファイル | 内容 |
|---|---|
| `ai-fukugyo.md` | AI×副業。**記入例**（そのまま使わず、自分のものを作る） |
| `mile.md` | マイル・陸マイラー。**記入例** |
| `ryori.md` | 料理・時短ごはん。**記入例** |
| `_template.md` | 新しいジャンルを作るときのひな形 |

## テーマの決まり方

1. ユーザーが指定していればそれを使う（「マイルのテーマで」「料理のnote書いて」など）
2. 指定がなく、記事の内容から明らかならそれを使う
3. どちらでもなければ**ユーザーに聞く**。勝手に既定を使わない

**名前（`label`）や冒頭に「記入例」と付いたテーマ（`ai-fukugyo.md` `mile.md` `ryori.md`）は、本人のテーマとして使わない。**
書き方の見本で、中の失敗談や実績は本人のものではない。本人のテーマが無ければ、`_template.md` から1枚作ってから記事を書く。

## 増やし方

1. `_template.md` をコピーして `<ジャンル名>.md` にする
2. 中の項目を埋める。**`（要記入）` や `（例：` が残っている項目は、記事を作る前にユーザーに伝えて埋めてもらう**（特に誘導先と保存先）。ファイルの中に「記入例」という言葉は入れない（入っていると、点検で記入例とみなされ、本人のテーマに数えられない）
3. この README の表に1行足す

## 何が変わるか

| 項目 | 効く工程 |
|---|---|
| 読者・ジャンル | 構成（note-outline）・本文（note-write） |
| 記事の目的 | 締めの誘導の強さ（note-outline / note-write） |
| 文体（一人称・語尾・呼びかけ方・絵文字・NGワード） | 本文（note-write） |
| 文章のサンプル・お手本にしたい書き手 | 本文（note-write）・見出しの言い回し（note-outline） |
| 立ち位置・強み（失敗と実績） | 自己開示と数字（note-outline / note-write） |
| 記事の長さとペース | 想定文字数（note-outline / note-write） |
| 図解の配色・画像の好み | 画像（note-image） |
| 誘導先（CTA）・CTA固定画像 | 構成・本文の締め |
| 効いたネタ | ネタ選び（note-auto） |
| 触れない話題 | 構成・本文・画像のすべて |
| 事実確認が要る話題・使ってはいけない表現 | 本文の裏取りとコンプラ（note-write） |
| 保存先（Notion・作業フォルダ） | 保存（note-auto）・入稿（note-toukou） |

## 共通で変わらないもの

次はテーマによらず同じ。テーマ側に書かない。

- 記事の骨格（リード→本文→まとめ＋CTA）
- 逃げ道フレーズ・自己開示を入れる方針
- 採点ループ（総合95点以上）
- 画像の枚数の目安（ワンスクロールに最低1枚＝500字に1枚）
- 図解の3段構成（見出し／本体／まとめ帯）とレイアウトの型
