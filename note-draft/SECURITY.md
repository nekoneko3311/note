# SECURITY — このツールの安全方針

このツールの一番大事な目的は、**作業を楽にしながら事故を防ぐこと**です。

## 絶対にしないこと

- note のパスワードをコード・`.env`・ログに書かない／保存しない
- Cookie やログイン済みセッションを Git に入れない
- 自動で公開しない／予約投稿しない
- 既存記事を上書きしない／削除しない
- エラー時に投稿系ボタンを連打しない
- CAPTCHA や2段階認証を自動で突破しない

## ログイン情報の扱い

- 初回だけ、あなたがブラウザ上で**手動ログイン**します。
- 保存するのは note の「ログイン済み状態」だけで、保存先は `storage/note-auth.json`。Google などのボタンでログインしても、note以外のサイトのログイン情報は捨ててから保存します。ファイルは本人だけが読める権限で作ります（Macの場合。Windowsではこの設定は効きません）。
- このファイルは秘密情報に近い扱いです。次を守ってください。
  - `.gitignore` に登録済み（GitHubに上げない）
  - チャットに貼らない／メールで送らない／共有フォルダに置かない
  - 中身をログに出さない
  - **AI（Claude・Codex）にも中身を開かせない・表示させない**（開くと会話の記録として送られ、手元にも残るため）
  - キットをやめるときは、ゴミ箱に移したあと**ゴミ箱を空にする**（空にするまで使える状態で残る）

## 公開事故を防ぐ設計

- **公開処理を実装していません**。コード上、公開ボタンは押しません。押すのは「下書き保存」と、画像の切り抜き画面の「保存」（名前が完全に一致するものだけ）です。
- `src/selectors.ts` に公開系ボタンの文言を書いてありますが、どこからも使っていません（何が公開ボタンかを読む人に示すための控えです）。
- 将来、自動公開をやる場合も、別フェーズで「下書き作成 → 人間の確認 → 明示的な承認 → 1記事ずつ」を必須にしてください。

## ログに出してよいもの / ダメなもの

- 出してよい：記事フォルダ名／タイトル／本文文字数／画像ファイル名／成功・失敗ステップ／スクリーンショット保存先／下書きURL
- 出してはいけない：パスワード／Cookie／認証トークン／`storage/note-auth.json` の中身／本文の全文

本文は全文をログに残しません（文字数だけ記録します）。
