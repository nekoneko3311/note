# note-auto-draft — noteの下書きを自動で作るツール

> **この文書は、自分でコマンドを打つ人と、動かなくなったときに中を調べる人のためのものです。**
> 普段はClaudeに「入稿して」と伝えるだけで、ここに書いてあることは全部やってくれます。

記事のテキストと画像をフォルダにまとめておくと、コマンド1つで **note.com の「下書き」まで**自動で作ります。
**公開ボタンは自動で押しません。** 最後は必ず、あなたがnoteの画面で確認してから手で公開します。

> なぜ下書きまでか：誤公開・重複投稿・画像抜け・ログイン切れの事故を防ぐためです。

---

## 使うために必要なもの

- Node.js が入ったPC（Mac / Windows。Windowsはベータ対応）
- Google Chrome / Chromium が動くPC
- note のアカウント（自分でログインできること）
- 入稿したい記事フォルダ（`article.md` ＋ 画像）

（部品の取り込み（`npm install`）は導入のときに済ませてあります。キットを新しい版に入れ替えたときだけ、もう一度実行します）

---

## いちばん最初に1回だけ：ログイン

```
npm run login
```

- ブラウザが開きます。**あなたが手動で note にログイン**してください。
- ログインを検知すると自動で保存し、ブラウザが閉じます（Enter入力は不要）。
- 「実際にエディタを開けるか」で確認するので、本当にログインできたときだけ保存します。
- パスワードは保存しません。noteのログイン済みの状態だけを `storage/note-auth.json` に保存します（Google などのボタンでログインしても、そのサイトのログイン情報は捨てて保存します。ファイルは本人だけが読める権限で作ります（Macの場合。Windowsではこの設定は効きません））。
- Google などのボタンで止められたときは、noteのログイン画面の「パスワードをお忘れの方」からパスワードを作り、メールアドレスでログインしてください。
- 確認のために編集画面を開くので、noteに空の下書きが1件できます。消してかまいません。

一度やれば、しばらくは再ログイン不要です（ログインが切れたら、もう一度これを実行）。

## 記事フォルダの作り方

`articles/` の中に、記事ごとのフォルダを作ります。

```
articles/
  my-article/
    article.md        ← 本文（下記の書き方）
    thumbnail.png     ← サムネイル（見出し画像）／任意
    images/
      fig1.png        ← 本文中に入れる画像
      fig2.png
```

`article.md` の書き方：

```markdown
---
title: 記事のタイトル
thumbnail: ./thumbnail.png
tags:
  - AI
  - 副業
---

本文をふつうに書きます。

![説明](./images/fig1.png)

## 見出し

続きの本文。

![説明](./images/fig2.png)
```

- 画像は `![説明](パス)` と書いた場所に入ります。
- 画像を押したときにURLを開かせたいときは、画像だけの行に `[![説明](パス)](https://…)` と書きます。本文を入れ終えたあとで、画像にリンクを付けます。
- 対応画像：`.png` `.jpg` `.jpeg` `.webp`（`.gif` `.svg` などは非対応）

## 実行の流れ

### 1. 事前チェック（noteには触りません）

```
npm run dry-run -- articles/my-article
```

タイトル・本文文字数・画像の枚数・サムネイルの有無を確認します。ここでエラーが出たら直します。

### 2. 下書きを作る

```
npm run draft -- articles/my-article --headed
```

- **必ず画面ありモード（--headed）で実行してください。** noteのエディタは画面なし(headless)だと読み込めません。
- ブラウザが開いて、noteの新規投稿画面に入力していきます。
- タイトル → サムネイル（見出し画像）→ 本文 → 本文画像 → **下書き保存** の順です。
- 終わると「下書きURL」を表示します。noteの画面で中身を確認してください。

> 注意：`npm run` に渡す引数は `--` を1回だけ付けます（`-- articles/... --headed`）。`-- ... -- --headed` のように `--` を2回付けるとエラーになります。

うまくいかないときは、画面を残して調べられます：

```
npm run draft -- articles/my-article --headed --pause-on-error
```

### 3. 公開

**このツールは公開しません。** note の画面で内容を確認し、問題なければ **あなたが手で公開**してください。

## 困ったとき

- まず環境を点検： `npm run doctor`
- 失敗時は `screenshots/` に画面が、`logs/note-auto-draft.log` に手順の記録が残ります（本文全文やパスワードは記録しません）。成功したときは、入れた画像の数・末尾に回った画像の数（`imagesLeftOver`）・リンクカードの数・カードにならなかったURLも記録されます。
- 「タイトル欄が見つからない」等が出たら、noteの画面が変わった可能性があります。下の「画面が変わって動かなくなったら」を見てください。

## 割り切っていること

- **画面ありモード必須**：noteエディタはheadlessだと読み込めないため、`--headed` で実行します。
- **記法はそのまま入ります**：見出し（`##` `###`）・太字・箇条書き・番号リスト・引用・コードブロックは、noteの書式に変換されて入ります。
- **表は箇条書きに変わります**：noteに表の機能が無いためです。「**項目**：説明」の形になり、ヘッダ行と区切り行は落ちます。3列以上は2列目以降が「 / 」でつながります。表の見た目のまま載せたいときは、画像にして貼ってください。
- **区切り線（`---`）は落ちます**：noteに該当する機能が無いためです。章の区切りは見出しで表現してください。
- **インラインコード（`` ` ``）は普通の文字になります**：noteに変換規則が無いため、記号だけ外します。強調したい語は太字か「かぎかっこ」にしてください。
- **画像は本文中の正しい位置に入ります**：本文を上から打ちながら、`![](…)` と書いた場所でその画像を差し込みます（`--no-inline-images` を付けると末尾にまとめます）。まれに入れられなかった画像は末尾に回るので、その場合は下書き画面でドラッグ移動してください。実行の最後の表示（または `logs/note-auto-draft.log` の `draft:done` の行）で、末尾に回った画像が 0 枚なら全部が正しい位置に入っています。
- **1回実行するごとに新しい下書きが1件作られます**：同じ記事で複数回試すと下書きが増えます。不要なものは note の下書き一覧から手動で削除してください（このツールは削除しません）。
- 自動公開・予約投稿・既存記事の編集/削除・複数アカウント・CAPTCHA/2段階認証の自動突破は**やりません**。

## 画面が変わって動かなくなったら

noteのエディタ更新でボタンや入力欄の場所が変わると失敗することがあります。直す場所は症状で分かれます。

| 症状 | 見るファイル |
|---|---|
| タイトル欄・本文欄・下書き保存ボタンが見つからない | `src/selectors.ts` |
| 本文の見出し・箇条書き・リンクカードが崩れる | `src/noteEditorAdapter.ts` の `fillBody` |
| 本文の画像・見出し画像が入らない | `src/noteEditorAdapter.ts`（`insertImageAtCursor`・`setThumbnail`） |
| 画像にリンクが付かない | `src/noteEditorAdapter.ts` の `applyImageLinks` と `src/selectors.ts` の `imageLink〜` |

画面の作りを調べるときは `node scripts/inspect-editor.mjs` を使います（ブラウザの画面が開きます。noteの編集画面は画面なしだと読み込めないためです）。

同梱のスクリプトは7本だけです。

| スクリプト | 何をするか |
|---|---|
| `verify-full.mjs <下書きURL>` | 入稿された本文の並びを、見出し・画像（リンクの有無つき）・リンクカード・番号リストなどの印つきで出し、最後に数をまとめる。記事の上から下まで1画面ずつの画面写しも `screenshots/verify-full-<日時>/` に保存 |
| `verify-draft.mjs <下書きURL>` | 下書き画面のスクリーンショットを撮る |
| `inspect-editor.mjs` | noteの編集画面の構造を調べる（`selectors.ts` を直すとき） |
| `render-figure.mjs <html> <out.png> <幅> <高さ>` | HTMLから図解の画像を作る（Codexが無いときの図解） |
| `shot-url.mjs <URL> <out.png> <幅> <高さ> [full]` | Webページのスクリーンショットを撮る（記事に貼る操作画面。noteにログイン済みなら、その状態で撮る） |
| `annotate.mjs <in.png> <out.png> <幅> <高さ> '<JSON>'` | 撮った画面に赤い枠・矢印・ラベルを重ねる |
| `annotate-side.mjs <in.png> <out.png> <幅> <高さ> '<JSON>' [余白]` | 画面の左にラベルを並べて、手順を示す（**出力は余白のぶん横に広がる**） |

詳しい安全方針は [SECURITY.md](./SECURITY.md) を見てください。
