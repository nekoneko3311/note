# 挿入画像のデザインの型（HTML/CSSで作る用）

noteの挿入画像として読みやすいよう決めた統一デザイン。**Codexなしで図解を作るとき**（`render-figure.mjs` でHTMLから画像にするとき）は、これに合わせる。

> 役割の分け方：**どの型（比較2カラム・3ステップなど）にするかは `zukai-style.md`** から選ぶ。このファイルは、その型を**HTMLで組むときの色・文字・部品の決まり**。

> 色は**テーマ設定の「図解の配色」が優先**。ここに書いてある色は、テーマ側に指定が無いときの既定値として読む。

## カラー

| 用途 | 色 |
|---|---|
| 背景 | クリーム/オフホワイト。上ほど淡いグラデ `linear-gradient(168deg,#fffdf9,#fdf4e7)` |
| アクセント | オレンジ `#F5822B`（濃いめ `#F0872B`、淡い面 `#FDECDA`） |
| 濃色文字 | 濃紺 `#1B2A4A`（ほぼ黒） |
| 本文グレー | `#41495c` / 補足 `#6b7280` |
| 比較の「ダメな側」 | グレー系。「良い側」はオレンジ |
| チェックOK | 一部グリーン `#3FA968` |

多色にしたいとき（ステップごとに色分け）は、オレンジ→緑→黄→紫→ピンクの順が既存の全体図で使われている。

## レイアウトの型（ほぼ全画像で共通の3段）

1. **上段：見出し**
   - 極太ゴシック（`font-weight:900`）、`font-family:"Hiragino Sans","Noto Sans JP"`
   - キーワードを1つだけオレンジに。さらに一語に**下線**（`::after` で `#fbcf9e` の太線を敷く）
   - `"引用符"` で囲む強調も既存で多用
2. **中段：図解本体**
   - 2カラム比較 / 3ステップ / カード群 / チャットUI / フォルダツリー / 配線図 / 人物イラスト＋吹き出し
3. **下段：オレンジの帯**
   - `#F5822B` の角丸帯に白抜きの太字でまとめ一言。キーワードだけ濃紺に反転させることも
   - 先頭に濃紺丸のチェックアイコン等を置く

## 部品

- **角丸カード**：白地 + オレンジ細枠（`2.5px solid #f4b271`）、`border-radius:22〜26px`、やわらかい影 `0 12px 26px rgba(190,130,50,.10)`
- **番号バッジ**：丸オレンジ `#f5822b` に白抜き数字。カード上辺に半分かぶせる（`top:-27px`）
- **チャットUI**：濃紺ヘッダーバー + 吹き出し（AI=グレー`#eef1f5`左寄せ / ユーザー=オレンジ淡`#fce7d4`右寄せ）+ 入力欄
- **アイコン**：必ず**インラインSVG**（線画、`stroke-width:3`前後）。絵文字は使わない
- **人物イラスト**：年代や雰囲気はテーマ設定の「読者」に近づける。やわらか線画・細い茶色の輪郭・淡い彩色。Codexの `/imagegen`（gpt-image-2）で緑一色の背景で作り、背景を抜いてから配置する（`SKILL.md` の「背景を透過させたいとき」）。Codexが無いときは人物イラストを入れない
- **配線図（MCP等）**：オレンジのケーブル + 中央に角丸オレンジのラベル、左右をカードでつなぐ

## タイポグラフィの注意

- `word-break:keep-all; line-break:strict` を body に入れる（日本語が単語の途中で折れるのを防ぐ）
- 長い行は読点や文節の位置で `<br>` を手動で入れると自然
- カード幅が狭いと1行に入らず崩れる。フォントを1px下げるかカード幅を広げて調整

## 作り方の全体像

日本語が正確でレイアウトが緻密なので、**図解の枠・文字・アイコン・カードはコード（HTML/CSS）**で作り、
**人物・ロボットのイラストだけ画像生成AI**で作って配置する「合成」がこのデザインの作り方。このスキルもその方針。

## 出力サイズの目安

- 横長図解：`1600 x 900`（シンプル）〜 `1600 x 1130`（要素が多い配線図など）
- 人物イラスト単体：`1024 x 1024`
- `render-figure.mjs` は `deviceScaleFactor:2` で出力するので、実ファイルは指定の2倍解像度（note掲載に十分）
