# note-write — 発信note本文作成

承認された構成（note-outline）を、発信note本文に仕上げる工程。文体ルールを最優先で守り、**AI感を消す**。

> これは自分の発信・集客note専用。クライアントから請け負うSEO記事には向かない。

## 参照

**最初に `~/note-kit/note-themes/` のテーマ設定を読む。** どのテーマかが決まっていなければ、ここで聞く。

テーマ設定から引くもの：

- **書き手**（一人称・語尾の基調・使わない言い回し・**読者への呼びかけ方**・**絵文字と装飾**）
- **文章のサンプル**（その人が実際に書いた文章。**語彙・リズム・句読点の打ち方をここに寄せる。**空欄なら書き手の項目だけで書く。参考URLがあれば、必要に応じて読みに行く）
- **お手本にしたい書き手**（あれば。リズムと言い回しの参考にする。**丸写しはしない**）
- **読者**（知識レベル。専門用語をどこまで崩すか）
- **記事の目的**（信頼づくり／集客／販売。締めの誘導の強さを合わせる）
- **記事の長さとペース**（目標文字数はここから引く。無記入なら 2,500〜4,000字）
- **立ち位置・強み**（うまくいかなかった経験＝自己開示の素材／実績・いま取り組んでいること＝数字の素材。**盛らない**。**収入・売上の額は、書いてあっても本文に出さない**＝下の「コンプラ」）
- **CTA固定画像**（その節があれば。毎回入れるバナーの位置・altテキスト・画像のリンク先・下に置くURL）
- **事実確認が要る話題**（そのジャンルで必ず裏を取るもの）
- **触れない話題**（**本文に出さない**。例に使うのも不可）
- **使ってはいけない表現**（ジャンル固有のNG。景表法・薬機法など）
- **保存先**（noteDB）／状態は「下書き」・日付は当日で保存

## 前提

- 構成が承認済みであること。まだなら **note-outline** を先に案内して止まる。

## 文体ルール（最優先）

一人称・語尾・使わない言い回し・**読者への呼びかけ方**・**絵文字と太字の量**は、**テーマ設定のとおり**にする。
テーマ設定に「絵文字を使わない」とあれば1つも使わない。「太字は少なめ」なら1セクション1か所までに絞る。
以下はテーマによらず共通。

- 語尾は**同じものを連打しない**（文末を不揃いにする）
- 一文は短め（1〜2行）、1段落は2〜3文
- **太字**でキーメッセージを1セクション1〜3か所だけ強調
- `_`（アンダースコア）を含む語は太字にしない。ファイル名などは「かぎかっこ」で囲む（noteで太字に変換されず、`**` が文字のまま残る）
- 箇条書きで手順・要素を整理
- 番号リスト（1. 2. 3.）に説明を添えるときは、番号の行のすぐ下に**空行を入れずに**書く。空行をはさんで段落にすると、noteでは番号が1からやり直しになる
- 各セクションに逃げ道（「まずここだけでOK」「今日のゴール」）
- 自己開示（「僕も最初は〜」）を要所に入れて属人性を出す
- 説教くさい締め・きれいにまとめる締めはしない（言い切らずに終わってよい）
- **本文の先頭に、タイトルと同じ見出し（`# タイトル`）を書かない。** タイトルは `article.md` の frontmatter の `title:` で入るので、本文にも書くと二重になる。本文はリードの文章から始める

## AI感を消す（重要）

- 同じ主張を三段で言い換えない（「たとえば／言い換えると／つまり」の重ね打ちを避ける）
- 教科書的な書き出し（「近年〜」「〜について解説します」）を使わない。冒頭は読者の"あるある"や自分の実体験から入る
- クッション表現（「〜だったりします」等）の機械的な多用を避ける

## 事実・正確性

- **テーマ設定の「事実確認が要る話題」**に当たるものは、断定する前に **WebSearch で裏取り**する（例：AI×副業ならClaudeの機能名や仕様、マイルなら必要マイル数や年会費、料理なら保存期間や加熱条件）
- 裏が取れないものは「〜の場合があります」等に弱めるか、書かない
- 機能は変わりやすいので、必要なら「◯年◯月時点」を添える

## コンプラ

- 共通のNG語・景表法リスク語（絶対／必ず／誰でも／100%／日本一／確実に／保証）を使わない
- **noteの規約で禁止されている書き方をしない**（[noteクリエイター規約](https://terms.help-note.com/hc/ja/articles/44943817565465)。どのテーマでも共通）
  - **売上・利益を見せて購入を煽る書き方**（10.1(3)。運営が事前の通知なしに利用停止できる）。「月◯万円稼いだ」「売上◯円」などの収入の額を、記事・講座・商品への誘導に使わない
  - **著しく誤解を招く表現**（9.1(11)）。「必ずもうかる」「誰でも稼げる」「確実に結果が出る」など
- **実績は収入の額で書かない。** 本人がテーマ設定に収入の数字を書いていても、収入額は本文に出さない。実績は「書いた本数」「続けた期間」「やったこと」など、お金以外の事実で書く
- **テーマ設定の「使ってはいけない表現」**も必ず守る（ジャンルごとに増える）
- **テーマ設定の「触れない話題」は本文に出さない。** たとえ話や例として出すのも不可
- 収益は「目指す」等、断定を避ける

## 手順

1. 承認済み構成と、この文体ルールを読み込む。
2. リード（問題提示→解決イメージ→メリット→安心感）→ 各H2/H3 → まとめ＋CTA の順に執筆する。
3. **CTA固定画像を入れる**（テーマ設定にその節があるときだけ）。詳細は下の「CTA固定画像」参照。
4. 事実主張は裏取りし、独自の表現で書く（見本を写さない）。
5. **採点＆修正ループを回す**（合格ライン＝総合95点以上）。詳細は下の「修正ループ」参照。**この段階ではまだ保存しない**（会話内の下書きを対象に採点・修正する）。
6. 合格（95点以上）に達したら本文を確定する。テーマ設定に「noteDB」の指定があるときだけ、**Notionに下書き保存**する（状態＝下書き・日付＝当日）。タイトルは決定タイトル、本文は Notion Markdown（##／###・太字・箇条書き・コードブロック）で構成を反映する。外部書き込みなので、この保存の前にだけ確認する。指定が無ければこの保存は行わない。
7. 実際の文字数・最終スコア（保存した場合は保存ページのURLも）を伝える。

## CTA固定画像

テーマ設定に「CTA固定画像」の節があるときだけ入れる。無いテーマでは何も足さない。

- 表に書かれた**ファイル・位置・altテキスト・画像のリンク先・下に置くURL**のとおりに入れる。位置を自分で変えない
- 記事フォルダに書き出すときの書き方（`images/` にコピー済みの相対パス）：

```markdown
![無料セミナーの案内](./images/cta-seminar.png)
```

- 「画像のリンク先」にURLがある画像は、次のように書く。入稿のときにツールが画像そのものにリンクを付ける（押すとURLが開く）。**画像だけの行に書く**（前後に文字を置かない）。表にこの列が無い古いテーマ設定では、上のリンクなしの書き方のまま

```markdown
[![公式LINEの友だち追加](./images/cta-line.png)](https://…)
```

- Notionに保存する本文では、画像は入れずに文章だけにする（画像は記事フォルダとnote側で入る）
- 「画像の下に置くもの」にURLの指定がある画像は、画像の直後にURLを置く（画像にリンクを付けた場合も置く。画像を押せることに気づかない人がいるため）。**URLだけの行にしないこと**（noteが自動でリンクカードに変え、ページ情報を持たないURLだと「タイトル未設定」と表示される）。`友だち追加はこちらから https://…` のように**文章と同じ行**に入れる
- **画像を続けて並べない。**あいだに必ず文章を挟む
- この画像は図解の枚数（500字に1枚）に数えない

## 修正ループ（合格ライン：総合95点以上）

本文を書いたら、保存の前に「採点→修正→再採点」を自動で繰り返し、95点以上にしてから保存する。

- **採点基準**：次の7項目（文字数／テーマのキーワード／NG語・景表法／文体の一致／独自性／事実の裏取り／検索対策）を0〜100で採点し、加重平均（独自性・事実は各20%、他は各12%程度）で総合点を出す。
- **必ずWeb検索する**：独自性（特徴的な一文を3〜5本、1本ずつ検索）と事実の裏取り（テーマ設定の「事実確認が要る話題」）は、毎回WebSearchで実照合する。検索せずに合格にしない。
- **回し方**：総合95点未満、または❌／⚠️があれば、その指摘を本文に反映して直し、再採点する。**95点以上になるまで自動で繰り返す**（1回ごとのユーザー確認は不要）。ただし構成・文体・事実・NG語のルールは崩さない。
- **保存は最後の1回だけ**：ループ中は書き込まない。95点に達してから、確認のうえ一度だけ保存する。
- **止まる条件**：何度直しても特定の項目が95点に届かない、または事実の裏が取れない場合は、無理に数字を合わせず、どの項目がなぜ届かないかを報告して一度止まる。

## 注意

- 構成にない話を勝手に足して文字数を稼がない。必要なら構成の追記を提案する。
- Notionへの保存は外部書き込み。保存前に確認する（テーマ設定にnoteDBの指定が無ければ保存自体を行わない）。
- 迷ったら「これ、本人（テーマ設定の書き手）が書いた感じに読めるか？」を基準にする。
